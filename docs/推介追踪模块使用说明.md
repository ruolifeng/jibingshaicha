## 1. 模块是做什么的

推介追踪管理用于两类工作：

| 场景                            | 用哪个子菜单 | 一句话                             |
| ------------------------------- | ------------ | ---------------------------------- |
| 把对象交给其他单位/用户继续处理 | **推介**     | 先发通知单，对方确认后再追踪、诊断 |
| 本单位自己直接追踪、诊断        | **追踪**     | 手动新增或导入大疫情后直接追踪     |

**正确理解：**

- 推介不是「填完就结案」，而是「移交 → 接收 → 追踪到位 → 再录入诊断」。
- 诊断一般在**追踪到位之后**再录；过早录入诊断会导致记录进入「已归档」，后续追踪会被系统拦截。

## 2. 「推介」和「追踪」有什么区别

| 对比项         | 推介                           | 追踪                                                       |
| -------------- | ------------------------------ | ---------------------------------------------------------- |
| 用途           | 跨单位/跨用户移交              | 本单位主动追踪                                             |
| 是否选接收人   | **必须选**（一至五级用户）     | 一般不需要（跨镇大疫情除外）                               |
| 是否要对方确认 | **需要**（确认接受 / 拒绝）    | 不需要（跨镇大疫情需区县三级确认）                         |
| 确认后在哪追踪 | **仍在「推介」页**开展追踪     | 在「追踪」页操作                                           |
| 未到位几次结束 | **4 次**未到位自动结束         | **3 次**未到位自动结束                                     |
| 共同追踪       | 有（同辖区三/四/五级可一起追） | 已确认的推介**不会出现在本页**；共同追踪请回「推介」页操作 |
| 大疫情导入     | 无                             | 有                                                         |

> **重要：** 推介被对方「确认接受」后，记录留在 **「推介」页**继续追踪，**不会**自动跑到「追踪」页。请在「推介」页点「追踪 / 共同追踪」。

## 3. 标准业务流程（必读）

### 3.1 推介标准流程（推荐照此执行）

```text
① 发起方：新增推介（填写基本信息 + 推介原因 + 选择接收人）
        ↓  注意：新建时「诊断结果」建议先不要选
② 系统发送推介通知单（列表推介状态显示为：**已发送**，等待对方确认）
        ↓
③ 接收方：在「推介」页点「确认接受」，或在「系统消息」中点「确认接收」
        ↓  （若拒绝，流程结束并归档，这是正常规则）
④ 发起方 / 接收方（开启共同追踪后还有同辖区三/四/五级）：在「推介」页开展「追踪」
        ↓  （每次追踪必须填写备注；选「到位」还须选择到位日期）
⑤ 追踪结果：
   - 到位 → 再分别「录入诊断 / 录入感染检测 / 录入胸片」
   - 未到位 → 可多次追踪；累计 4 次未到位自动强制结束并归档
   - 其他 → 仅记备注，不算结束，可继续追
        ↓
⑥ 「录入诊断」后：本条推介归档结案（选「潜伏感染者」还会生成潜伏管理数据）
```

### 3.2 追踪标准流程

```text
① 手动新增，或「大疫情导入」
        ↓
② 点「追踪」：到位 / 未到位 / 其他
        ↓
③ 到位后：分别「录入诊断 / 录入感染检测 / 录入胸片」
        ↓
④ 按诊断结果结案或分流（潜伏感染者会进入潜伏管理）
```

## 4. 推介页：逐步操作说明

菜单：**推介追踪管理 → 推介**

### 4.1 新增推介（发起方）

> 需具备推介新增权限；超管或一至五级用户（且开通了新增权限）可见「新增推介」。

1. 点击 **「新增推介」**。
2. 填写必填项：
   - **姓名**、**联系电话**、**现住址**、**人群分类**
   - **推介原因**
   - **推介接收人**（必填；可选一至五级用户，下拉显示为「用户名（单位）」）
3. 可选项：证件号、感染检测/胸片信息等。
4. 点击 **「发送推介」**（新建成功后系统会立刻发出推介通知）。

#### ⚠ 新建时「诊断结果」怎么选？（极易误操作）

创建表单里有一个 **「诊断结果」** 选项（排除、正常、疑似结核、确诊结核、潜伏感染者、在治患者、拒绝、陈旧性结核）。

| 做法                 | 结果                                             |
| -------------------- | ------------------------------------------------ |
| **不选**（强烈推荐） | 记录保持进行中，对方确认后可正常追踪、开共同追踪 |
| **选了任意一项诊断** | 系统按「已出诊断」处理，**保存后立即归档结案**   |

因此：

> **推介尚未追踪到位时，请不要勾选「诊断结果」。**
> 诊断应在对方确认、追踪「到位」之后，再点操作列里的 **「录入诊断」**。

若新建时误选了诊断，常见现象：

- 列表「追踪状态」仍可能是「待追踪」
- 「推介状态」也可能已是「已发送 / 已接受」
- 一点「追踪」保存或开「共同追踪」，提示：**「该记录已归档，无法继续追踪 / 无法开启共同追踪」**

这属于**业务规则拦截**，不是按钮坏了。

> 「追踪」页新建时若同样勾选了诊断结果，也会立刻归档，规则相同。

### 4.2 推介状态流转

| 列表显示 | 含义                                                   | 下一步谁操作                   |
| -------- | ------------------------------------------------------ | ------------------------------ |
| 未发送   | 已建档但未发出（少见；正常新建会直接发送）             | 发起方可再点「发送推介」       |
| 已发送   | 已发给接收人，等待确认（系统消息里也称「待确认推介」） | 接收方点「确认接受」或「拒绝」 |
| 已接受   | 接收方已确认                                           | 可开始追踪 / 共同追踪          |
| 已拒绝   | 接收方拒绝                                             | **流程结束并归档**（正常）     |

接收方可在：

- **推介**列表操作列点 **「确认接受」** / **「拒绝」**
- 或顶部 **系统消息** 中处理「待确认推介」（消息里的按钮文案为 **「确认接收」**，作用相同）

### 4.3 确认接受后怎么追踪

1. 确认推介状态为 **「已接受」**。
2. 在操作列点击 **「追踪」**。
3. 选择追踪结果并**必须填写备注**：
   - **到位**：需选择到位日期
   - **未到位**：累计次数 +1；满 4 次自动强制结束并归档
   - **其他**：只记本次备注，**不结束**，还可继续追踪
4. 保存成功后，列表「追踪状态」会更新。

弹窗底部提示含义示例：

> 「第 1 次追踪，当前已未到位 0 次，4 次未到位将自动结束追踪」

表示：这是第几次操作、已经有几次未到位、再满几次会自动结案。

### 4.4 到位之后做什么

追踪状态变为 **「到位」** 后，操作列会出现三个独立按钮（可分别填写，不必一次做完）：

| 按钮             | 作用                                       |
| ---------------- | ------------------------------------------ |
| **录入诊断**     | 正式结案关键步骤；选完诊断后本条推介会归档 |
| **录入感染检测** | 补录是否检测、日期、方法、结果             |
| **录入胸片**     | 补录是否胸片、日期、结果                   |

诊断选项：排除、正常、疑似结核、确诊结核、潜伏感染者、在治患者、拒绝、陈旧性结核。

| 诊断结果                                   | 系统行为（概要）                                 |
| ------------------------------------------ | ------------------------------------------------ |
| 排除 / 正常 / 疑似结核 / 拒绝 / 陈旧性结核 | 归档结案                                         |
| 确诊结核 / 在治患者                        | 结案归档（确诊类可在列表显示结案标识）           |
| 潜伏感染者                                 | 归档本推介记录，并在 **潜伏感染者管理** 生成数据 |

**一旦通过「录入诊断」正式结案归档，一般不可再继续追踪。**
（到位后建议先完成需要的感染检测/胸片，再录入诊断：诊断保存后，列表上的「录入感染检测 / 录入胸片」按钮通常会消失。）

### 4.5 其他常用按钮

| 按钮             | 作用                                          |
| ---------------- | --------------------------------------------- |
| 查看             | 看详情、推介信息、追踪过程                    |
| 编辑             | 改基本信息等（已正式结案归档时限制更多）      |
| 删除             | 删除本条（需有删除权限，请谨慎）              |
| 共同追踪         | 开启后同辖区三/四/五级可一起追踪（见第 8 章） |
| 同意编辑共同追踪 | 三级以上可向四/五级开放「修改追踪过程」权限   |
| 打印 / 保存 PDF  | 在新建或详情中打印推介单                      |

## 5. 追踪页：逐步操作说明

菜单：**推介追踪管理 → 追踪**

### 5.1 适用场景

- 本单位自己录入对象并追踪
- **大疫情报告卡导入**后批量追踪
- 查看/处理本辖区「追踪」类数据

> **已确认接受的推介不会出现在「追踪」列表。**
> 推介的追踪、共同追踪、录入诊断请一律在 **「推介」页** 完成。

### 5.2 手动新增

1. 点击新增，填写必填项：**姓名、联系电话、现住址、人群分类、追踪原因**。
2. 保存后，在列表点 **「追踪」**（每次须填备注；到位须选到位日期）。
3. 到位后再「录入诊断 / 感染检测 / 胸片」。

> 与推介相同：**新建时不要勾选「诊断结果」**，否则会立刻归档，无法再追踪。

### 5.3 大疫情导入

1. 在追踪页点击 **「大疫情导入」**，按提示上传大疫情网（报告卡）导出的 `.xlsx / .xls`。
2. 系统提取报告卡字段并创建追踪记录（来源显示为「大疫情」）。
3. 若部分对象属跨镇范围，导入时需为各乡镇选择 **区县三级用户** 作为确认人；对方确认前不可追踪，拒绝则归档。
4. 确认后按「追踪 → 到位 → 诊断」继续处理。

### 5.4 未到位次数规则（与推介不同）

| 模块                          | 未到位上限 | 达到上限后      |
| ----------------------------- | ---------- | --------------- |
| 推介                          | **4 次**   | 强制结束 + 归档 |
| 追踪（本单位追踪 / 大疫情等） | **3 次**   | 强制结束 + 归档 |

请按所在页面规则理解，不要混用。

## 6. 状态与标签说明

### 6.1 推介状态

| 列表显示 | 含义                                                   |
| -------- | ------------------------------------------------------ |
| 未发送   | 尚未发出（正常「新增并发送」流程较少长期停留在此）     |
| 已发送   | 已发出，等待接收人确认（消息中心显示为「待确认推介」） |
| 已接受   | 接收人已确认，可追踪                                   |
| 已拒绝   | 拒绝接收，已结束归档                                   |

### 6.2 追踪状态

| 显示     | 含义           | 能否继续追踪                                       |
| -------- | -------------- | -------------------------------------------------- |
| 待追踪   | 还没做过追踪   | 可以                                               |
| 到位     | 已联系到对象   | 不再点「追踪」；改为「录入诊断 / 感染检测 / 胸片」 |
| 未到位   | 本次没到位     | 可以（未满次数上限）                               |
| 其他     | 特殊情况备注   | 可以（不算正式结案）                               |
| 强制结束 | 未到位次数用尽 | **不可以**                                         |

### 6.3 共同追踪状态（如何判断已开启）

推介列表**没有单独一列**「共同追踪」，可通过以下方式判断：

| 怎么看                                 | 含义                         |
| -------------------------------------- | ---------------------------- |
| 操作列仍有 **「共同追踪」** 按钮       | 尚未开启                     |
| 操作列出现 **「同意编辑共同追踪」**    | 已开启（且当前账号有权授权） |
| 点 **「查看」** → 详情里的「共同追踪」 | 显示「未开启 / 已开启」      |

开启后：同辖区三/四/五级可参与追踪，未到位次数合并计算。

## 7. 「已归档」到底是什么意思

「已归档」表示：系统认为这条推介/追踪业务**已经结束或结案**。
多数情况下，归档后不能再按「进行中」去追踪；少数「误归档且无诊断」的历史数据，再次操作时可能被系统自动恢复（见 7.2）。

### 7.1 哪些操作会导致归档（正常规则）

| 序号 | 原因                                  | 是否正常                   |
| ---- | ------------------------------------- | -------------------------- |
| 1    | **新建推介/追踪时勾选了「诊断结果」** | 正常规则，但**极易误操作** |
| 2    | 追踪「到位」后正式「录入诊断」        | 正常结案                   |
| 3    | 推介侧未到位累计 **4** 次             | 正常强制结束               |
| 4    | 追踪侧未到位累计 **3** 次             | 正常强制结束               |
| 5    | 接收方 **拒绝** 推介                  | 正常结束                   |
| 6    | 跨镇导入被拒绝                        | 正常结束                   |

> 说明：新建时若勾选诊断，系统会在发出推介的同时归档。对方仍可能「确认接受」，但之后追踪/共同追踪会失败——这是规则拦截，不是接收坏了。

### 7.2 归档后系统会怎样

可能出现的提示（属于规则拦截，不是随机故障）：

- `该记录已归档，无法继续追踪`
- `该记录已归档，无法开启共同追踪`
- `该记录已归档，无法修改诊断结果`（已有正式诊断时）

说明：

1. **新建时勾选了诊断 / 已正式录入诊断 / 强制结束 / 已拒绝**：属于正式结案类归档。此时即使页面上还能看到「追踪」「共同追踪」按钮，**保存时会被拒绝**。
2. **极少数「误归档」**（例如历史数据：状态仍是待追踪/未到位，且**没有诊断结果**）：再次点追踪或开启共同追踪时，系统可能自动解除归档并允许继续。这不代表所有「已归档」都能恢复。

客户遇到「待追踪却提示已归档」时，优先检查是否 **新建时勾选了诊断结果**。

### 7.3 客户最容易误会的一点

> 「我刚录入、追踪状态还是待追踪，为什么说已归档？」

常见真实原因：

1. 新建时勾选了诊断结果 → 系统按「已诊断结案」归档；
2. 或该条曾被拒绝 / 已满未到位次数 / 已正式录入过诊断。

**处理建议：**

- 新推介：新建时**不要选诊断**；
- 已误归档：联系管理员核查该条「诊断结果 / 推介状态 / 未到位次数」，按业务决定是否重新建档或后台纠正。

## 8. 共同追踪怎么用

### 8.1 什么时候需要

接收方确认后，若需要同辖区 **三级、四级、五级** 一起参与追踪，可开启共同追踪。

### 8.2 怎么开启

前提：

- 推介状态为 **已接受**
- 记录 **未正式结案归档**（尤其不要在新建时误选诊断）

方式：

1. 操作列点 **「共同追踪」** → 确认开启；或
2. **四级用户**在追踪时选择「未到位」并保存后，系统可询问是否开启共同追踪。

开启后：

- 三/四/五级可参与追踪；
- 各方操作次数 **合并计算**；
- 推介侧仍按 **4 次未到位** 自动结束。

### 8.3 「同意编辑共同追踪」

- 共同追踪开启后：有权限的参与人仍可 **新增** 追踪操作（到位/未到位/其他）。
- 若要 **修改已经填写过的追踪过程（历史记录）**，须三级以上（超管/一/二/三级）用户点 **「同意编辑共同追踪」**，勾选向 **四级 / 五级** 开放编辑权限。
- 未授权时：共同追踪过程可能只能查看，改历史会提示未开放编辑权限。

### 8.4 开不了共同追踪时先自查

1. 是否已「确认接受」（列表为「已接受」）？
2. 是否已经是「已开启」？
3. 是否已归档（新建误选诊断 / 已录入诊断 / 强制结束 / 已拒绝）？
4. 当前账号是否为：**发起方、接收方、四级（同辖区）或超管**？
   （普通三/五级未开启前不能点「共同追踪」开启；开启后三/四/五级才能参与追踪）

## 9. 角色与权限（谁能点什么）

> 角色编号供管理员对照：超管=1，一级=2，二级=3，三级=4，四级=5，五级=6。
> 具体按钮还受「权限管理」配置影响；下列为业务侧常见规则。

| 操作                   | 常见可操作角色                              |
| ---------------------- | ------------------------------------------- |
| 新增/发送推介          | 超管，或一至五级且具备新增权限              |
| 确认接受 / 拒绝        | **该条指定的推介接收人**（或超管）          |
| 追踪（未开共同追踪）   | 发起方、接收方（及超管）                    |
| 开启共同追踪           | 发起方、接收方、同辖区四级、超管            |
| 共同追踪开启后参与追踪 | 发起方、接收方，以及同辖区三/四/五级        |
| 同意编辑共同追踪       | 三级以上（超管/一/二/三级），且对该记录有权 |
| 导出 / 删除            | 需具备对应权限点                            |

看不到按钮时，优先确认：账号角色、权限点、是否本人接收、推介是否已接受、是否已归档结案。

## 10. 常见问题：是操作问题还是系统故障

### Q1：刚录入就提示「已归档，无法继续追踪」

**多数不是 Bug。**
请检查新建时是否勾选了「诊断结果」。
正确做法：新建只填推介信息 → 发送 → 对方确认 → 再追踪 → 到位后再录入诊断。

---

### Q2：能点「追踪」，但保存失败，提示已归档

**多数不是 Bug。**
按钮可点 ≠ 一定允许保存。常见原因：

- 新建时勾选了诊断，或已正式「录入诊断」结案
- 已强制结束、或推介已拒绝

请在详情/列表中核对：**诊断结果是否有值、推介状态、未到位次数、是否强制结束**。

---

### Q3：共同追踪确认后失败，提示已归档

**多数不是 Bug。**
与 Q1/Q2 相同：正式结案类归档不允许开启共同追踪。先解决归档原因（尤其新建误选诊断）。

---

### Q4：选了「其他」，为什么还能继续追踪？

**这是正常设计。**
追踪结果里的「其他」= 本次备注特殊情况，**不等于结案**。
真正结束通常是：到位后「录入诊断」、未到位次数用尽、或推介被拒绝。

---

### Q5：未到位几次会自动结束？

| 页面 / 业务                     | 次数     |
| ------------------------------- | -------- |
| 推介页（推介业务）              | **4 次** |
| 追踪页（本单位追踪 / 大疫情等） | **3 次** |

达到后状态变为「强制结束」并归档，不能再追。

---

### Q6：确认接受后，为什么在「追踪」页找不到？

**不是 Bug。**
系统设计就是：已确认推介 **只在「推介」页** 开展追踪与共同追踪，不会进入「追踪」列表。
请回到 **推介追踪管理 → 推介**。

---

### Q7：四级选未到位后弹出「是否开启共同追踪」，点取消行不行？

**可以。**
取消只表示不开共同追踪；本次「未到位」记录仍会保存。之后也可再手动点「共同追踪」。

---

### Q8：诊断选「潜伏感染者」后去哪了？

本条推介/追踪会归档，并在 **潜伏感染者管理** 中生成对应数据。
请到潜伏模块继续通知单、督导等流程。

---

### Q9：提示「推介通知单尚未被接收方确认，暂不可追踪」

**正常拦截。**
接收方必须先「确认接受」，之后才能追踪。

---

### Q10：提示无权开启共同追踪 / 看不到「共同追踪」按钮

**先对角色：**

- 能开启：发起方、接收方、同辖区四级、超管
- 开启后能参与追踪：同辖区三/四/五级
- 五级用户一般不能「开启」，但共同追踪开启后可以参与

---

### Q11：什么情况才需要报系统故障？

在排除下列情况后，再联系技术支持：

- [ ] 新建时未选诊断
- [ ] 推介已接受
- [ ] 追踪状态不是强制结束
- [ ] 未正式「录入诊断」结案
- [ ] 账号角色与权限符合上文规则
- [ ] 在正确的菜单页操作（推介业务在「推介」页）
- [ ] 仍无法保存，且提示与上述规则不符

报障时请提供：**姓名、证件号、推介状态、追踪状态、是否有诊断结果、未到位次数、操作账号、完整报错原文、操作时间**。

---

## 11. 操作检查清单（发给一线人员）

### 发起推介前

- [ ] 接收人选对单位与人员
- [ ] 推介原因已填写
- [ ] **未勾选「诊断结果」**（除非业务明确要求新建即结案）
- [ ] 点击的是「发送推介」

### 接收后追踪前

- [ ] 状态已是「已接受」
- [ ] 在 **推介** 页操作，不是找错菜单
- [ ] 追踪备注已填写；选到位时已填到位日期

### 共同追踪前

- [ ] 已接受
- [ ] 未归档、未强制结束、无过早诊断结案
- [ ] 当前账号有权开启

### 结案前

- [ ] 已追踪到位
- [ ] 需要的感染检测 / 胸片已补录（建议诊断前完成）
- [ ] 再点「录入诊断」（不要在新建阶段提前选诊断）
- [ ] 知晓录入诊断后将归档，一般不能再追

## 附录 A：一句话口诀

> **推介先移交，确认后再追；到位再诊断，诊断即归档。**
> **新建别勾诊断，未到位推介满四次结束。**
> **共同追踪要已接受且未结案；推介业务请在「推介」页操作。**

## 附录 B：与「转诊」的区别（避免混用）

| 名称     | 在哪用                           | 含义                              |
| -------- | -------------------------------- | --------------------------------- |
| **推介** | 推介追踪管理 → 推介              | 主动建档并指定接收人移交          |
| **转诊** | 筛查/潜伏/患者等模块中的转诊按钮 | 已有业务记录上报/转给其他医疗机构 |

二者名称相近，流程不同，请勿混为一谈。
